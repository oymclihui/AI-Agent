# 企业邮箱助手（IMAP）

## 适用场景

- 用户已在 **设置 → 邮箱账户** 中配置 **邮箱地址** 与 **邮箱密码**（IMAP）
- 需要汇总未读/最近邮件、提取待办、回复草稿建议

## 前置条件

1. 调用 `fetch_mail` 工具前，确认用户已在平台设置中保存邮箱凭据
2. 邮箱服务器默认为 BYD：`imap.byd.com:1993`（SSL）
3. **绝不**向用户索要或重复存储邮箱密码；仅使用平台已保存的凭据

## 操作步骤

1. 理解用户意图（最近几封、某主题、来自某人等）
2. 调用 `fetch_mail`，参数：
   - `limit`：默认 10，最大 20
   - `folder`：默认 `INBOX`
3. 按主题/发件人/时间整理摘要
4. 若用户需要回复，基于邮件内容给出草稿（不自动发送）

## 输出格式

```markdown
## 邮件摘要
- 共 N 封

### 1. [主题]
- 发件人：
- 时间：
- 要点：

## 建议行动
- ...
```

## 注意事项

- 密码重置邮件由平台 SMTP 发送，与用户邮箱 IMAP 凭据无关
- 若 `fetch_mail` 报错，提示用户检查设置中的邮箱与密码，或使用「测试连接」
