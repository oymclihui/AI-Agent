# 企业邮箱助手（IMAP）

## 适用场景

- 用户已在 **设置 → 邮箱账户** 中配置 **邮箱地址** 与 **邮箱密码**（IMAP）
- 需要汇总未读/最近邮件、提取待办、回复草稿建议

## 前置条件

1. 调用 `fetch_mail` 工具前，确认用户已在平台设置中保存邮箱凭据
2. 邮箱服务器默认为 BYD：`imap.byd.com:1993`（SSL）
3. **绝不**向用户索要或重复存储邮箱密码；仅使用平台已保存的凭据

## 操作步骤

1. 理解用户意图（最近几封、某主题、来自某人等）
2. 调用 `fetch_mail`，参数：
   - `limit`：默认 10，最大 20
   - `folder`：默认 `INBOX`
3. 按主题/发件人/时间整理摘要
4. 若用户需要回复，基于邮件内容给出草稿（不自动发送）

## 输出格式

```markdown
## 邮件摘要
- 共 N 封

### 1. [主题]
- 发件人：
- 时间：
- 要点：

## 建议行动
- ...
```

## 注意事项

- 密码重置邮件由平台 SMTP 发送，与用户邮箱 IMAP 凭据无关
- 若 `fetch_mail` 报错，提示用户检查设置中的邮箱与密码，或使用「测试连接」

## 案例

### 案例 1：汇总最近邮件

用户：帮我看最近 5 封邮件里有没有今天要处理的

1. 调用 `fetch_mail`，`limit=5`，`folder=INBOX`。不要向用户要密码。
2. 按下面的格式回复，只根据工具返回的邮件写要点。

```markdown
## 邮件摘要
- 共 5 封，其中 2 封建议今天处理

### 1. [周会纪要请确认]
- 发件人：zhangsan
- 时间：今天 09:12
- 要点：请在下班前确认出席

## 建议行动
- 回复确认出席
- 另一封月报抄送无需今天处理
```

### 案例 2：起草回复，不代发

用户：帮我回复第一封，说我下午三点到

基于该封邮件写一封短草稿，明确告诉用户「未发送」。不要调用任何发信动作。
