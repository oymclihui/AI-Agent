# 5 维设计评审（Huashu Design）

## 维度（各 0–10）

1. **哲学一致性** — 是否贯彻所选风格/设计师 DNA  
2. **视觉层级** — 字号对比 ≥2.5×，眯眼测试仍清晰  
3. **细节执行** — 间距系统（8pt 网格）、对齐、色数 ≤4  
4. **功能性** — 每元素有存在理由，CTA 显眼  
5. **创新性** — 避免 AI cliché，有独特但合理的决策  

## 场景侧重

| 场景 | 优先 |
|------|------|
| 落地页 | 功能性、视觉层级 |
| PPT | 视觉层级、功能性（每页 1 观点） |
| 信息图 | 功能性、层级 |
| App 原型 | 功能性、细节 |

## Top 问题速查

- AI 渐变圆球 / 电路板 cliché  
- 标题正文字号差不足  
- 颜色 >5 种无系统  
- 间距随意、对齐混乱  
- 装饰抢内容、PPT 信息过密
